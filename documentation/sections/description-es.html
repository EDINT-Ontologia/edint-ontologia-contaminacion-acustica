Ontología EDINT de Contaminación Acústica: Descripción volver a índice

Como se muestra en la Figura 1, esta ontología extiende la ontología de medioambiente de EDINT añadiendo cinco propiedades para especificar las características concretas de una observación de ruido: tipo de emisor de ruido predominante, intervalo de referencia para ruido, tipo de índice para ruido, ponderación de ruido, y tipo de constante de tiempo para el ruido, que están conectados a sus conceptos SKOS correspondientes: tipo de emisor de ruido predominante, intervalo de referencia para ruido, tipo de índice para ruido, ponderación de ruido y tipo de constante de tiempo para el ruido.

A continuación mostramos un ejemplo en RDF, usando la notación RDF Turtle, que describe una observación del nivel de presión sonora equivalente con ponderación A (normalmente simplificado con LAeq) y cuyo tipo de emisor predominante es un vehículo automóvil.
