Síntesis

Esta ontología intenta proporcionar el vocabulario común para representar las principales entidades y datos de sensores y observaciones sobre contaminación acústica. Es una actualización de una versión previa de la ontología, que adapta esa ontología para cubrir los requisitos del Espacio de Datos para las Infraestructuras Urbanas Inteligentes (EDINT). También amplia la ontología de medioambiente para el caso de la contaminación acústica.
