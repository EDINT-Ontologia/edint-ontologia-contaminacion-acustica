EDINT Noise Pollution Ontology: Description back to ToC

As shown in Figure 1, this ontology extends the environment ontology of EDINT by adding five properties to specify the specific characteristics of a noise observation: predominant noise emitter type, noise reference interval, noise rate type, noise weighting, and noise time constant type, which are linked to their corresponding SKOS concepts: predominant noise emitter type, noise reference interval, noise rate type, noise weighting and noise time constant type.
